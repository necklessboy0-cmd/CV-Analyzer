# CV Analyzer

A professional Streamlit-based CV analysis application powered by **Google Gemini 3.5 Flash-Lite**.

## Features

- PDF, DOCX, and TXT CV upload
- Deep CV audit using Gemini
- Overall score from 0–100
- Executive summary, strengths, and critical issues
- Section-by-section analysis
- Micro-level grammar, spelling, punctuation, capitalization, spacing, wording, and consistency checks
- Missing-information analysis
- Recruiter/ATS readability guidance
- Contact and link analysis
- Automated text diagnostics
- Prioritized recommendations
- Professional final assessment
- Premium purple/dark-purple/gold interface
- Lightweight animated background
- Error handling for invalid files, missing API keys, API errors, and invalid AI responses
- Gemini is the only AI/external API used by the application
- No external URL is fabricated or generated by `app.py`
- Cloudflare Tunnel is kept outside `app.py` and can be used from Google Colab

## Gemini API Key

Do **not** hard-code the Gemini API key in `app.py`.

For Google Colab, create a Colab Secret named:

```text
GEMINI_API_KEY
```

Then load it into the runtime:

```python
import os
from google.colab import userdata

os.environ["GEMINI_API_KEY"] = userdata.get("GEMINI_API_KEY")
print("Gemini environment configured.")
```

The application also supports `GEMINI_API_KEY` through Streamlit Secrets or the environment.

The intended Colab flow is:

```text

    ↓

```

Install Cloudflare Tunnel in Colab:

```python
!wget -q https://github.com/cloudflare/cloudflared/releases/latest/download/cloudflared-linux-amd64.deb

```

Verify:

```python
!cloudflared --version
```

Load the Gemini secret:

```python
import os
from google.colab import userdata

os.environ["GEMINI_API_KEY"] = userdata.get("GEMINI_API_KEY")
```

Validate `app.py`:

```python
!python -m py_compile app.py
```

Start Streamlit:

```python
!streamlit run app.py --server.address 0.0.0.0 --server.port 8501 > streamlit.log 2>&1 &
```

Then expose that running Streamlit service through Cloudflare:

```python
!cloudflared tunnel --url http://127.0.0.1:8501
```

Cloudflare generates the temporary public `trycloudflare.com` address. No Cloudflare tunnel code is required inside `app.py`.

## Supported Files

### PDF
Text is extracted from text-based PDFs. Scanned/image-only PDFs may have no extractable text.

### DOCX
Paragraphs and table content are extracted.

### TXT
UTF-8 and common fallback encodings are supported.

## Analysis Output

The application produces:

- Overall score
- Score explanation
- Executive summary
- Strengths
- Critical issues
- Section analysis
- Detailed errors
- Missing information
- Recommendations
- Link analysis
- Final assessment

It also displays deterministic text diagnostics such as word count, link count, repeated punctuation, spacing issues, and detected sections.

## Security

The Gemini key is read at runtime from a secret/environment variable. The UI does not display the key, and the application does not intentionally print or log it.

Uploaded CV content is sent to Gemini for analysis. Only upload documents you are authorized to process.

## Limitations

The application analyzes extractable document text. Text extraction cannot reliably determine every visual design property such as exact fonts, graphical elements, colors, alignment, or page layout.

AI findings should be reviewed by the user before making important career decisions.

## Error Handling

Common failures are handled for:

- Missing Gemini API key
- Unsupported/empty files
- Corrupt documents
- Image-only PDFs
- Large extracted text
- Gemini authentication errors
- Gemini quota/rate-limit errors
- Empty Gemini responses
- Invalid JSON responses
